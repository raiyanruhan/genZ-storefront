# ZENJI Web Application

ZENJI is an anime inspired streetwear brand. This repository contains the official frontend web application for ZENJI. The application provides a seamless, modern, and highly responsive shopping experience for exploring our curated streetwear collections.

## Overview

The ZENJI frontend is built to deliver high performance, maintainability, and scalability. It leverages modern web development tools and follows a strict architectural pattern to ensure code quality.

## Features

* Product Catalog: Browse through a dynamically filtered list of streetwear items.
* Authentication: User registration and login functionality.
* Shopping Cart: Manage products and quantities.
* User Profile: View order history and manage personal details.
* Responsive Design: Optimized for both desktop and mobile devices.

## Technology Stack

* Framework: Vue 3
* State Management: Pinia
* Language: TypeScript
* Routing: Vue Router
* Styling: SCSS
* Mock Backend: DummyJSON for product data and Firebase for authentication

## Architecture

The project strictly follows the Feature Sliced Design architecture to ensure clear boundaries and separation of concerns across different layers of the application.

## Setup Instructions

1. Clone the repository.
2. Install dependencies using npm install.
3. Set up the required environment variables.
4. Start the development server using npm run dev.
5. Build for production using npm run build.
